# Vuelvo Vacío

Cada vuelta cuenta.

Proyecto de plataforma web para conectar transportistas con capacidad disponible en sus viajes de retorno y empresas que necesitan trasladar cargas en Uruguay.

## Estado

Etapa inicial de definición. Este repositorio contiene la documentación de arranque; todavía no incluye una aplicación ejecutable ni servicios desplegados.

## Objetivo del MVP

- Registrar transportistas y empresas.
- Publicar retornos con origen, destino, fecha, vehículo y capacidad disponible.
- Publicar cargas y sus necesidades de transporte.
- Buscar publicaciones compatibles por ruta, fecha y tipo de vehículo.
- Facilitar el contacto por WhatsApp.
- Permitir cerrar publicaciones que ya no estén disponibles.

## Stack propuesto

- Next.js y TypeScript para la aplicación web.
- Tailwind CSS para la interfaz responsive.
- Supabase: PostgreSQL y autenticación.
- Vercel como alternativa de alojamiento, sujeto a validar plan y condiciones antes del lanzamiento.
- GitHub para código y documentación versionada.
